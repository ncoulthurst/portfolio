Eskens Ops

An operations app that sits on top of our CRM's API and turns rows of job data into a live map of the UK, with every job as an icon. 40+ staff use it every day, from helpdesk and field engineers to projects, the warehouse, IT and senior stakeholders. I planned, designed, built and deployed it on my own.

Next.js React TypeScript Postgres Python Azure Entra ID PWA

Overview

Engineers used to track jobs in their own spreadsheets. Work got missed, and engineers would drive past jobs they didn't know about because the job was sitting in someone else's file.

The CRM holds everything as rows of data. Eskens Ops pulls those rows through the CRM's API and plots them on a map of the UK, with each job as an icon, so anyone in the business can see what's happening and where at a glance. Jobs sync live, so a job added while an engineer is out on the road still reaches them.

I built it end to end on my own: planning, design, the Next.js app, the Python data pipeline, the Azure deployment and the rollout to the team.

What it does

One app for the whole business: helpdesk, field engineers, projects, the warehouse, IT and senior stakeholders.

01 / Job map

Live job map

Every job from the CRM plotted as an icon on a map of the UK, instead of a row in a table.

02 / Scheduling

Service scheduling

Service visits scheduled from the work orders and monthly service schedules the pipeline pulls in.

03 / Rota

Team rota

The rota sits next to the jobs, so who's working and what needs doing are in the same place.

04 / IT

IT ticket queue

Internal IT requests are raised and tracked in the same app the team already has open.

05 / Warehouse

Installation stages

The warehouse tracks each new installation through its stages, so everyone can see where it's up to.

06 / Stock

NFC stock tracking

PC stock is tagged with NFC, so the warehouse can track machines with a tap instead of a spreadsheet.

How it works

A Python pipeline pulls three sources into one Postgres database. The app reads from that database and turns every job into an icon on a map of the UK.

Built as an app

Eskens Ops is a progressive web app, so staff install it on their phone or computer like any other app and get notifications from it.

Staff sign in with their Microsoft accounts through Entra ID, so there are no new passwords to hand out or reset.

The app runs on Azure App Service with an Azure Postgres database.
